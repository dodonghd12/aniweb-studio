AniWeb Studio landing page

Files:
- index.html — self-contained website

Quick deployment options:
1. GitHub Pages
   - Create a new public repository.
   - Upload index.html to the repository root.
   - Open Settings → Pages.
   - Deploy from the main branch / root.
   - GitHub will give you a public URL.

2. Netlify
   - Go to Netlify Drop.
   - Drag and drop index.html (or the entire aniweb-studio folder).
   - Netlify will generate a public URL immediately.

Important:
- The page intentionally describes AniWeb Studio as an early-stage / MVP project.
- Edit the contact email in index.html if you want to use a different address.
